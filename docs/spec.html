LineLog

按级别过滤的最小 C++17 日志库。一条语句里用 << 接上正文，再用 EndLine 换行。

行为

  • 调用方创建一个临时对象，带上级别、文件名和行号。
  • 同一条语句里可以多次 << 字符串。前缀只出现一次，后面的字符串原样接上，中间不加空格。
  • EndLine 结束这一行。
  • 全程序共用一个最大级别。当前日志的级别数字更大时，整条语句不产生任何输出，包括换行。
  • 最大级别可以在运行中用 SetMaxLevel 修改。
级别 Error = 0，Warn = 1，Info = 2，Debug = 3。数字越大越细。只有当前级别小于等于最大级别才打印。默认最大级别是 Info。

不包含

  • 宏，以及自动填入文件名和行号。这两项由调用方传入。
  • 线程号、缩进、写文件和锁。
一次一条 正在书写的这一行保存在进程内的共享状态里。不要让两条日志的 << 交错执行。

示例

src/demo.cc：

#include "line_log/line_log.h"

int main() {
  logx::LineLog(logx::Level::Info, "main.cc", 10) << "服务" << "已启动" << logx::EndLine{};
  logx::LineLog(logx::Level::Debug, "main.cc", 11) << "细节" << logx::EndLine{};
  logx::LineLog(logx::Level::Error, "main.cc", 12) << "连接失败" << logx::EndLine{};
  logx::LineLog(logx::Level::Warn, "main.cc", 13) << "磁盘将满" << logx::EndLine{};
  logx::LineLog::SetMaxLevel(logx::Level::Debug);
  logx::LineLog(logx::Level::Debug, "main.cc", 14) << "细节" << logx::EndLine{};
  return 0;
}

运行 bazel run //:line_log_demo，标准输出是：

[info] 2026-10-06 23:13:05.123 main.cc:10: 服务已启动
[error] 2026-10-06 23:13:05.124 main.cc:12: 连接失败
[warn] 2026-10-06 23:13:05.125 main.cc:13: 磁盘将满
[debug] 2026-10-06 23:13:05.126 main.cc:14: 细节

时间是打印这一行时的本地时间，格式为 年-月-日 时:分:秒.毫秒。上面的时刻只是例子。默认上限是 Info 时，第 11 行的 Debug 整行消失，没有空行。"服务" 与 "已启动" 之间没有空格。前缀末尾、正文之前有一个空格。

颜色

整行按级别着色，换行前恢复默认颜色。设置了非空的环境变量 NO_COLOR 时，输出保持纯文本。

级别颜色
error红
warn黄
info绿
debug青

接口

包含 #include "line_log/line_log.h"。声明都在命名空间 logx 里。

enum class Level { Error = 0, Warn = 1, Info = 2, Debug = 3 };

struct EndLine {};

class LineLog {
 public:
  LineLog(Level level, const std::string& file, int line);
  static void SetMaxLevel(Level level);

  LineLog& operator<<(const std::string& text);
  LineLog& operator<<(const EndLine&);

 private:
  static Level max_level_;
  static Level current_level_;
  static std::string current_file_;
  static int current_line_;
  static bool header_done_;
};

前缀里的级别文字是小写的 error、warn、info、debug，不带方括号。方括号由输出格式另加。

构造、<< 和 EndLine 写在同一条语句里。语句结束时临时对象销毁。
